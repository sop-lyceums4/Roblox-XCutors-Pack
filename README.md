## FAQ

### What exactly is XCutors?

XCutors is a desktop application that serves as a management hub and launcher for various third-party Roblox script execution tools and a universal script loader.

### Is this a single executor?

No, XCutors is a collection. It packages several popular executors (Volt, Synapse Z, Potassium, Wave) and our custom universal loader, XCutorsLoader, into one easy-to-use suite.

### Do I need to download each executor separately?

No. The XCutors suite handles the download and updating of all included executors. You simply select which one you want to use from the interface.

### What is the XCutorsLoader?

It is our custom-made, universal script loader designed with a simple interface for attaching to Roblox and executing Lua scripts from a file or the built-in library.

### Are my accounts safe from being banned?

Using any third-party script execution tool carries inherent risk. We recommend using alternative accounts. XCutors itself does not include anti-detection features.

### Does this work on Mac or Linux?

No. XCutors and the included executors are developed specifically for the Windows operating system (Windows 10 and 11).

### How do I get updates?

The XCutorsLoader has a built-in update checker. It will notify you and download updates for the loader and any outdated executor files automatically when you launch the application.

### Is this project open source?

The XCutorsLoader interface and update system are open source. The individual executors are developed by third parties and are included as compiled binaries subject to their own licenses.
